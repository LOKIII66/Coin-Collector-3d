# 🪙 Coin Collector 3D

A 3D first-person coin collection game built with **Unity**.

## 🎮 About the Game

**Coin Collector 3D** is a first-person 3D game where the player explores different levels and collects **rupee coins** before the available time runs out.

Each level provides a different challenge, with coins placed throughout the environment and a limited amount of time to collect them.

## 🕹️ Controls

| Key     | Action        |
| ------- | ------------- |
| `W`     | Move Forward  |
| `A`     | Move Left     |
| `S`     | Move Backward |
| `D`     | Move Right    |
| `Mouse` | Look Around   |

## 🎯 Objective

* Explore each level.
* Find and collect the rupee coins.
* Collect as many coins as possible before the timer runs out.
* Complete the different levels within their time limits.

## ✨ Features

* 🎮 First-person gameplay
* 🪙 Rupee coin collection
* 🌍 Multiple levels
* ⏱️ Different time limits for levels
* 🎨 3D environments
* 🕹️ WASD movement
* 👀 First-person camera

## 🛠️ Built With

* **Unity**
* **C#**
* **3D Assets**
* **Unity Starter Assets**
